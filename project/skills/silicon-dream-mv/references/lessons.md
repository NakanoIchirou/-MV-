# 制作复盘：保留什么，停止什么

这些结论来自本项目的制作与v25抽帧审阅。创作判断是可讨论的，不应取代作者的明确选择。音乐的完整听感未在该次抽帧审阅中验证。

|经验|保留下来的做法|避免重复的损耗|
|---|---|---|
|用户能给出精确镜号和格位修改|固定M编号与格位，将意见转成映射再执行|口头说“改好了”，下轮又猜编号指向哪一版|
|保留通过的图比反复生成更稳定|冻结选用素材，候选独立保存|为修小问题全镜重画，人物和布局再次漂移|
|摄像机与场景关系曾反复出错|固定场景锚点、主体比例和运动方向|为构图强扭肢体、挪动物体，或逐格自动缩放|
|定格方案降低了制作难度|把更新频率、素材复用和拍子明确写入工程|宣称补全连续动画，实际上只交了幻灯片|
|倒计时跨M4–M6修改|检查连续状态链和声音落点|只改一个镜头的首尾，接镜时数字倒退|
|结尾采用前镜末帧、点击、黑屏|复用实际解码末帧，分开定义声音与黑屏时间|拿近似原画代替视频末帧，出现视觉跳变|
|逐镜审片和可重导出归档有效|成片、逐镜片段、映射、音乐和审片入口同存|只交一段MP4或过程报告，下一次无法接手|
|多轮高成本返工|先验证最难的短样段，再扩大工作量|换模型或增代理当作解决能力不足的默认办法|

## v25说明了哪些创作风险

- **信息推进慢于片长推进。** 约前50秒都在交代通勤。生活流程可以表达重复，但多个扶梯、闸机和车门段落若缺少新信息，会消耗观众等待主题的耐心。新项目粗剪阶段就检查这一点；本片改动须尊重锁定音乐与作者意图。
- **定格需要设计换帧意义。** 约46–54秒持续围绕车门构图，抽帧中动作推进有限。检查每次变化能否被观众识别，别把“八个格位都有文件”当作八个有效动作。
- **符号接力是值得保留的核心。** 黄色主体从通勤者延续到线路、芯片、信息和推荐，最后回到电脑前的人。视觉身份可以承担跨尺度叙事，减少解释文字。
- **中间态决定转场是否可信。** 约80.5、84.5秒出现悬空线条、断开连接与叠影。今后优先采用能验证的对象映射或更简单过渡，不能只审两个关键帧。
- **极简仍需可读。** 约58–60秒主体缩至很小的点线。缩小可表达个体与系统的尺度关系，但需同时检查缩略图/手机尺寸下能否看清。
- **题词需要影像支撑。** 首尾同句与回到房间的闭环建立呼应；不能只靠哲理文字替代中段表达。

## 用三个小场景检查这个skill是否被正确使用

**请求：只把M4第8格改成8，别画新图。** 找当前基线与格位映射，复用可用数字或做授权局部替换，保持画布和持续时间；验证M4末格到M5首格，渲染受影响镜头并拼接。不要重画M1–M12或改变整片节奏。

**请求：第一格删掉，所有后面向前移。** 结合当前格位语境确定“一格”的单位；对移动范围与末端补齐存在实质歧义时才问。修改前先保存输入映射，验证跨镜接续与总时长。

**请求：锐评这个半成品。** 查实际成片，说明抽帧或完整视听的证据范围；分别讨论构思、可读性、时间分配和完成度，引用具体时间。不会因指出问题就自行重剪，也不会替用户把已选定格形式判为错误。
